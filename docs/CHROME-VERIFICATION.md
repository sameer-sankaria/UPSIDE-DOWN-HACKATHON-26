# Real Chrome acceptance checklist — Phase 2

These checks are **not yet performed**. The automated suite uses Chrome API mocks and a real DOM tree with layout stubs. Follow README setup, configure NAVI_EXTENSION_ID, start the web app, and load/reload apps/extension/dist in Chrome 120+.

Use public, disposable fixture pages rather than sensitive browsing data.

1. **Load and Phase 1 regression:** Extension loads without manifest/service-worker errors. GET /api/health returns the exact Phase 1 JSON. On http://localhost:3000, `await window.naviOs.pingExtension("EXTENSION_ID")` returns a correlated NAVI_PONG. An external BROWSER_NAVIGATE message must return INVALID_MESSAGE. Another localhost port must return FORBIDDEN; a remote website must be blocked by Chrome.
2. **Separate tab permissions:** Open GitHub and react.dev. Open the popup on each and enroll metadata. Verify only those enrolled tabs appear and that no page content is extracted merely by enrollment. A third, unapproved tab must not appear or be injected. Ghost Mode remains disabled.
3. **No implicit content grant:** Connect the backend, select an enrolled tab without content consent, and click Analyze. It must reject with a content-permission error and no analysis POST.
4. **One/two authorized extractions:** Explicitly allow page text on one tab, then another. Select one/two and Analyze. Confirm backend POSTs receive origin-only URLs and bounded sanitized text, and recommendations are shown. Never select confidential pages.
5. **Sensitive fixtures:** On a local test document, include a visible main paragraph, a password field, an OTP field, a form, contenteditable text, data-private region, hidden text, email address, and six-digit code. Password/OTP control pages must block entirely. On a variant without those controls, only allowed visible prose should remain, with sensitive patterns excluded/redacted. Verify real viewport/visibility behavior.
6. **Navigation and revocation:** Grant content, navigate or reload, and confirm content consent is gone. Cross-origin navigation, closing a tab, or explicit Revoke must remove enrollment. Revoke page text must keep metadata while preventing further extraction. Browser restricted pages and incognito must be refused.
7. **Ghost detection:** Enable monitoring with GitHub + React docs enrolled. Confirm a development/React suggestion with a heuristic confidence score. Add an enrolled Stack Overflow tab; verify a stronger category signal. No tab opens and no API upload occurs merely because a suggestion appears. Repeated authorized activity after the cooldown should increment aggregate counters.
8. **No automatic execution:** With opening permission off, selected searches must not open. With permission on, no search opens until the explicit approval button is clicked. Choose two queries and approve: exactly two background Google search results pages should open, with those queries encoded. Replaying the consumed recommendation must not open additional tabs. No code or arbitrary destination URL is executed.
9. **Ghost controls:** Not Now dismisses for the session. Pause stops new observations and removes pending Ghost suggestions. Clear deletes counters/dismissals and pauses. Resume records again. Disable clears Ghost data and stops monitoring. Content extraction is unaffected by Ghost enable alone.
10. **Lifecycle and clear:** Suspend/restart the service worker and verify session grants/counters survive appropriately. Restart Chrome or reload the extension and verify session state resets. Use Revoke all permissions and clear NAVI session; verify empty tabs, counters, and pending suggestions; Ghost disabled; tab opening off; localhost host permission removed. Existing browser tabs remain open.
11. **Backend identity:** Wrong or missing NAVI_EXTENSION_ID must reject extension analysis requests. Correct ID after a web-server restart should permit them. Declining the optional localhost permission must prevent API transfer.

Remaining limitations are described in README and TESTING.md. These checklist items must not be reported as passed until observed in real Chrome.
